# Publication photographs

These are local WebP versions of real photographs selected for the nine publication topics. The source images have not been generated or retouched. Resizing and compression are the only asset changes; CSS crops the display to fit each placement.

The complete source register is `src/_data/publicationPhotography.json`: original titles, photographers, source pages, download URLs (or supplied local assets), licences, accessible descriptions, dimensions and responsive variants. Public attribution is rendered at `photo-credits.html`, linked beside every use and from the footer.

Creative Commons derivatives in this folder retain the licence recorded for the original photograph. The two summit photographs were supplied by SADGF for this website; this folder does not grant a licence for third-party reuse of those photographs.

For replacements, download the source identified in the register and use Sharp to rotate according to EXIF, resize without enlargement to widths 640 and 1600, and encode WebP at quality 80. Preserve the aspect ratio and use the original width when it is smaller. Update the register and `publications.json` together. The article feature, homepage and archive share the same publication image reference.
