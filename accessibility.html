Access to our work

Information about using this website and requesting help with SADGF resources.

✳People. Policy. Possibility.

Designed for different ways of browsing

This website supports keyboard navigation, visible focus indicators, browser zoom, responsive layouts and reduced-motion preferences. Publications are available as web pages, and the publication controls let you print or save a web edition as a PDF.

Documents and external services

Some original PDF documents and external services may have accessibility limitations. If a resource is difficult to use, contact us with the title or link and the format you need.

Report a barrier

Email info@sadgf.org.za with the page address, a description of the problem and, if useful, the browser or assistive technology you use. You can also use our contact form.
